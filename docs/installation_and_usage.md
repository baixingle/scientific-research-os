# Installation and Usage

## Concept

Scientific Research OS is a workflow framework, not a single AI model.

It can be adapted to different AI tools and execution environments.

## Tool Independence

The execution layer can use:

- coding agents;
- local models;
- API models;
- automation systems.

The framework only requires that execution agents follow explicit missions.

## Suggested Adoption

For individuals:

1. Copy templates into a project folder.
2. Maintain research memory.
3. Use review checklists before major conclusions.

For teams:

1. Define shared workflows.
2. Store project artifacts.
3. Maintain versioned decisions.

## Version Philosophy

Scientific Research OS evolves through evidence and practical usage, not feature accumulation alone.
