# Reviewer Mode

Reviewer Mode turns the Scientific Research OS onto itself.

The reviewer agent should not optimize for producing more content. It should identify weaknesses, unsupported assumptions, and missing validation.

## Reviewer Questions

### Scientific Question

- Is the question important?
- Is the knowledge gap real?
- Are competing explanations considered?

### Evidence

- What is directly supported?
- What is inferred?
- What remains unknown?

### Causality

- Is there temporal ordering?
- Is there a physical or logical bridge?
- Could alternative explanations explain the observation?

### Execution

- Was the task necessary?
- Was the computational or experimental cost justified?
- Were acceptance criteria defined before execution?

### Final Review

A strong result is not one with the strongest claim.

A strong result is one where the claim exactly matches the evidence.
