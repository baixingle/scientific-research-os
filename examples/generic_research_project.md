# Generic Research Project Example

This example is intentionally abstract and contains no domain-specific unpublished information.

## Initial Observation

A researcher observes a reproducible phenomenon that current explanations do not fully explain.

## Problem Framing

Question:

What missing information prevents current theory from explaining the observation?

## Competing Hypotheses

H0:
Existing framework is sufficient.

H1:
A missing structural variable contributes.

H2:
A missing dynamical variable contributes.

H3:
The observation results from sampling limitations.

## Strategy

Design the smallest study that can distinguish these hypotheses.

## Execution

Create a mission with:

- inputs;
- allowed operations;
- expected outputs;
- acceptance criteria.

## Interpretation

Separate:

- what was observed;
- what was localized;
- what mechanism is supported;
- what remains unknown.
