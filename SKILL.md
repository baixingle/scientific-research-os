# Scientific Research OS Skill

## Role

This skill defines a reusable operating framework for AI-assisted scientific research.

## Research Workflow

### Phase 1: Strategic Framing

Goal:
- Define scientific question
- Identify key uncertainty
- Establish hypothesis space
- Determine required evidence

Output:
- Research strategy document
- Decision framework

### Phase 2: Project Architecture

Create:
- Project roadmap
- Milestones
- Computational/experimental plan
- Data management strategy

### Phase 3: Task Execution

Execution tasks must contain:

- Objective
- Background context needed for execution
- Input files/resources
- Expected output
- Acceptance criteria

Avoid including high-level strategic discussions inside execution task files.

### Phase 4: Validation

Evaluate:

- Technical correctness
- Scientific consistency
- Reproducibility
- Evidence strength
- Limitations

### Phase 5: Knowledge Integration

Update:

- Research memory
- Decision history
- Methods
- Generalizable lessons

## Agent Collaboration Model

Human + Strategic AI:
- scientific reasoning
- prioritization
- interpretation

Execution AI:
- implementation
- data processing
- document generation
- reproducible operations

The separation between strategy and execution is fundamental.
