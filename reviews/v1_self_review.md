# Scientific Research OS v1.0 Self Review

## Purpose

Before releasing or extending a workflow, review the system using its own principles.

## 1. Architecture Review

- Are strategic reasoning and execution clearly separated?
- Are agent roles defined by function rather than by specific tools?
- Can a new executor agent be substituted without changing the scientific workflow?

## 2. Scientific Rigor Review

Check every major claim:

- Observation: What was directly measured?
- Interpretation: What does the observation suggest?
- Mechanism: What causal explanation is supported?
- Generalization: What broader principle is justified?

## 3. Workflow Review

Verify:

- The project starts from a scientific question.
- Tasks are created only after goals and acceptance criteria are defined.
- Results are reviewed before conclusions are made.

## 4. Memory Review

Important decisions should preserve:

- Decision
- Evidence
- Alternatives considered
- Confidence level
- Conditions that would change the decision

## 5. Improvement Question

The final question is:

> Does this change improve scientific understanding, or only increase activity?
