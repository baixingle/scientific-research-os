# Scientific Reasoning Reference

## Core idea

Scientific research should reduce uncertainty, not merely generate results.

## Workflow

Question → Hypothesis → Test → Evidence → Interpretation → Mechanism.

## Rules

- Separate observation from explanation.
- Prefer falsifiable hypotheses.
- Define success and failure before execution.
- Avoid constructing mechanisms from correlations alone.

## Research quality

A strong project identifies what current frameworks explain, what they fail to explain, and what new evidence would change understanding.
