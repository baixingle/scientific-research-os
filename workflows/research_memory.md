# Research Memory Workflow

## Purpose

Research memory should preserve decisions, reasoning, and evidence rather than raw conversation history.

## Memory Unit

Each important decision should record:

## Decision

What was decided?

## Evidence

What observations or analysis support it?

## Alternatives Considered

What other explanations were evaluated?

## Rejected Options

Why were alternatives not selected?

## Confidence Level

How strong is the current conclusion?

## Next Trigger

What future result would change this decision?

## Principle

A useful research memory stores scientific state, not conversation transcripts.
