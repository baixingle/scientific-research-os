# Resource Allocation Workflow

## Purpose

Research resources should be allocated according to expected information gain, not convenience.

Resources include:

- computational time;
- GPU/CPU hours;
- API cost;
- human review time.

---

# Decision Framework

Before starting an expensive task, define:

## Scientific uncertainty

What is unknown?

## Competing explanations

Which possibilities are being distinguished?

## Expected information gain

How will the result change the decision?

---

# Priority Rule

Prefer tasks that:

- eliminate major uncertainty;
- test competing hypotheses;
- create reusable knowledge.

Avoid tasks that only:

- produce more data;
- improve appearance;
- confirm assumptions.

---

# Stop Conditions

Stop when:

- the result cannot change the scientific decision;
- additional precision does not change interpretation;
- remaining uncertainty requires a different experiment.
