# Project Lifecycle Workflow

## Purpose

Define a reusable lifecycle for AI-assisted scientific projects.

## Stages

```
Idea
 ↓
Scientific Framework
 ↓
Roadmap
 ↓
Mission Design
 ↓
Execution
 ↓
Review
 ↓
Research Memory
 ↓
Publication Strategy
```

## Stage Requirements

### Idea

Must become a scientific question, not just a topic.

### Scientific Framework

Define:

- knowledge gap;
- competing hypotheses;
- evidence requirements.

### Roadmap

Define:

- milestones;
- decision points;
- stop conditions.

### Mission

Each execution task requires:

- objective;
- inputs;
- outputs;
- acceptance criteria.

### Review

Check:

- evidence strength;
- alternative explanations;
- claim boundaries.

## Principle

A project advances only when uncertainty is reduced, not simply when more data are generated.
