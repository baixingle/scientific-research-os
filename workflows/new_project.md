# New Project Workflow

## Goal
Transform an initial idea into a scientifically testable project.

## Steps

1. Collect background, constraints, available data, and objectives.
2. Build a Scientific Problem Map.
3. Identify knowledge, method, and data gaps.
4. Generate competing hypotheses.
5. Define evidence required to distinguish hypotheses.
6. Decide the minimum first experiment or calculation.

## Output Artifacts

- scientific_framework.md
- project_roadmap.md
- first_mission.md

## Gate
Do not start expensive work before the scientific uncertainty being reduced is explicit.
